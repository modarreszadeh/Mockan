# Mockan Panel — Project structure

> **Summary:** the `panel/` folder tree, what lives where, and the import rules ESLint enforces.

## Tree

```text
panel/
├── index.html
├── vite.config.ts               # base from VITE_PANEL_BASE_PATH (OQ-03), @ alias, Tailwind
├── vitest.config.ts             # jsdom, src/test/setup.ts
├── playwright.config.ts         # e2e against `vite` dev server + MSW; projects `chromium` (1440) and `mobile` (390)
├── eslint.config.js             # boundaries + no raw hex
├── components.json              # shadcn config (style radix-nova)
├── public/mockServiceWorker.js  # MSW worker (generated by `npx msw init public`)
├── e2e/                         # Playwright specs
└── src/
    ├── main.tsx                 # starts MSW (dev) then renders <App/>
    ├── app/                     # router, providers, query client, AppShell, auth guards, system pages
    ├── api/
    │   ├── client.ts            # fetch wrapper, ApiError, field-error mapping (OQ-F1)
    │   ├── types.ts             # arch §8 types, camelCase (OQ-F5)
    │   └── queries/             # key factories + hooks per resource (me, rules, services, logs, test-route)
    ├── components/
    │   ├── ui/                  # shadcn-generated; only token-level edits
    │   └── mockan/              # domain components (components.md)
    ├── features/
    │   ├── onboarding/  overview/  rules/  services/  settings/  admin/
    │   ├── logs/  test-route/   # Phase 2 (M5): SCR-09, SCR-10
    │   └── design/              # /__design style guide (dev only)
    ├── hooks/                   # generic hooks (media queries)
    ├── lib/                     # checks (zod-free), validation (zod schemas), precedence, format, http, config
    ├── mocks/                   # MSW: fixtures, db (scenarios), handlers/, matching.ts (test-route), live-log.ts (simulated hub, browser only), browser.ts, server.ts
    ├── styles/globals.css       # tokens + @theme inline + type utilities
    └── test/                    # setup, render helpers, fake-socket.ts (WebSocket stand-in), axe matcher types
```

## Import rules (enforced by `eslint.config.js`)

| Layer | May import | MUST NOT import |
| --- | --- | --- |
| `components/ui` | `lib`, `hooks` | `components/mockan`, `features`, `app` |
| `components/mockan` | `ui`, `lib`, `hooks`, `api` (MockKillSwitch uses rule queries) | `features`, `app` |
| `features/<x>` | `ui`, `mockan`, `lib`, `hooks`, `api` | other `features/<y>`, `app` |
| `app` | everything | — |
| `mocks`, `test` | everything | — (not shipped in production builds) |

`components/mockan` and `features` may not import `components/ui/sheet`, `dialog` or `alert-dialog` (use `Modal` / `ConfirmDialog`); the only exception is `confirm-dialog.tsx`. `ui/sidebar.tsx` keeps its own `Sheet` for the mobile navigation.

Rule of thumb: if two features need the same thing, move it down to `components/mockan`, `lib` or `api`.

## Scripts

| Script | Does |
| --- | --- |
| `npm run dev` | Vite dev server with MSW. |
| `npm run build` | `tsc -b` + Vite build to `dist/` (no MSW). |
| `npm run build:server` | Build and copy `dist/` to `../server/src/mockan/admin/static/` (D-11). |
| `npm run typecheck` / `lint` / `format` | TypeScript, ESLint, Prettier. |
| `npm test` / `npm run test:watch` | Vitest. |
| `npm run e2e` | Playwright. |
| `npm run check` | typecheck + lint + test + build (the milestone gate). |
